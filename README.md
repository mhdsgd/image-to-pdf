# 图片合并PDF工具

一款简单高效的图片合并PDF桌面软件，支持批量导入图片、拖拽排序、自定义页面布局和压缩质量，提供实时预览功能。

## 功能特性

- 支持JPG、PNG、WebP格式图片导入
- 支持批量导入，一次最多处理1000张图片
- 默认按文件名排序，支持手动拖拽排序
- 实时PDF预览，支持缩放和翻页
- 自定义页面大小（A4、Letter）
- 自定义页面方向（纵向/横向）
- 自定义页边距
- 多种压缩质量选项（原画质/高质量/中等/低质量）
- 自定义输出文件名
- 浅色/深色主题切换

## 安装方法

### 方式一：直接运行（推荐）

1. 下载最新版本的 `图片合并PDF工具.exe`
2. 双击运行即可

### 方式二：从源码运行

1. 克隆项目
```bash
git clone <repository-url>
cd image-to-pdf
```

2. 安装依赖
```bash
pip install -r requirements.txt
```

3. 运行程序
```bash
python main.py
```

## 使用说明

### 导入图片

1. 点击"导入图片"按钮
2. 选择要导入的图片文件（支持多选）
3. 图片将显示在左侧列表中

### 排序图片

- 默认按文件名排序
- 拖拽图片可调整顺序
- 右键菜单可进行删除、上移、下移操作

### 预览PDF

- 右侧面板实时预览PDF效果
- 使用"上一页"/"下一页"按钮翻页
- 使用"放大"/"缩小"按钮调整缩放

### 生成PDF

1. 点击"设置"按钮调整页面参数
2. 点击"生成PDF"按钮
3. 选择保存位置和文件名
4. 等待生成完成

### 设置选项

- **页面大小**：A4、Letter
- **页面方向**：纵向、横向
- **页边距**：0-200点
- **压缩质量**：原画质、高质量、中等、低质量
- **界面主题**：浅色、深色

## 常见问题

### Q: 支持哪些图片格式？
A: 支持JPG、JPEG、PNG、WebP格式。

### Q: 一次最多能处理多少张图片？
A: 一次最多处理1000张图片。

### Q: 生成的PDF文件太大怎么办？
A: 可以在设置中选择"中等"或"低质量"压缩选项。

### Q: 如何切换主题？
A: 点击"设置"按钮，在主题设置中选择"浅色"或"深色"。
