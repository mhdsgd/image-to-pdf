# 图片合并PDF工具

一款简单高效的图片合并PDF桌面软件，支持批量导入图片、多选排序、自定义页面布局和压缩质量，提供实时预览功能。

## 功能特性

- 支持JPG、PNG、WebP格式图片导入
- 支持从ZIP、7z压缩包直接导入图片
- 支持批量导入，一次最多处理1000张图片
- 内存优化：图片按需加载释放，批量处理时内存占用低
- 默认按文件名排序，支持多选排序（交换、置顶、置底）
- 左侧列表支持切换缩略图/仅名称两种显示模式
- 实时PDF预览，支持翻页、鼠标滚轮缩放、拖拽平移，自适应窗口大小
- 自定义页面大小（A4、Letter）
- 自定义页面方向（纵向/横向）
- 自定义页边距
- 多种压缩质量选项（原画质/高质量/中等/低质量）
- 自定义输出文件名
- 浅色/深色主题切换
- PDF生成进度条显示
- PDF生成容错：个别图片处理失败时自动跳过，不影响其余页面生成
- 大批量图片并行生成：超过30张自动启用多进程分块并行，充分利用多核CPU加速

## 安装方法

### 方式一：直接运行（推荐）

1. 下载仓库中的 `dist/图片合并PDF工具.exe`
2. 双击运行即可

### 方式二：从源码运行

1. 克隆项目
```bash
git clone https://github.com/mhdsgd/image-to-pdf.git
cd image-to-pdf
```

2. 安装依赖
```bash
pip install -r requirements.txt
```

3. 运行程序
```bash
python main.py
```

### 方式三：从源码打包（需要Python环境）

**前提条件：** 需要安装 Python 3.7+ 并添加到系统 PATH。

1. 克隆项目
```bash
git clone https://github.com/mhdsgd/image-to-pdf.git
cd image-to-pdf
```

2. 运行打包脚本
```bash
build.bat
```

打包完成后，可执行文件位于 `dist/图片合并PDF工具.exe`。

## 使用说明

### 导入图片

1. 点击"导入图片"按钮
2. 选择要导入的图片文件（支持多选）
3. 图片将显示在左侧列表中

### 导入压缩包

1. 点击"导入压缩包"按钮
2. 选择ZIP或7z格式的压缩包文件
3. 压缩包中的图片将自动解压并显示在列表中

### 切换显示模式

- 点击"仅名称"按钮可切换为纯文本列表模式，仅显示文件名不显示缩略图
- 再次点击"缩略图"按钮可恢复缩略图网格模式

### 排序图片

- 默认按文件名排序
- 按住Ctrl键点击图片可多选
- 选中2张图片后点击"交换位置"按钮可互换位置
- 选中1张或多张图片后点击"置顶"按钮可移到列表最前
- 选中1张或多张图片后点击"置底"按钮可移到列表最后
- 选中1张或多张图片后点击"删除选中"按钮可批量移除
- 右键菜单可进行删除、上移、下移操作

### 预览PDF

- 右侧面板实时预览PDF效果
- 使用"上一页"/"下一页"按钮翻页
- 鼠标滚轮可放大/缩小预览图片（最小为完整显示，最大为5倍）
- 点击"重置"按钮恢复默认缩放和位置
- 图片超出窗口时可鼠标拖拽平移查看

### 生成PDF

1. 点击"设置"按钮调整页面参数
2. 点击"生成PDF"按钮
3. 选择保存位置和文件名
4. 等待生成完成

### 设置选项

- **页面大小**：A4、Letter
- **页面方向**：纵向、横向
- **页边距**：0-200点
- **压缩质量**：原画质、高质量、中等、低质量
- **界面主题**：浅色、深色

## 常见问题

### Q: 支持哪些图片格式？
A: 支持JPG、JPEG、PNG、WebP格式。

### Q: 支持哪些压缩包格式？
A: 支持ZIP和7z格式的压缩包。

### Q: 一次最多能处理多少张图片？
A: 一次最多处理1000张图片。

### Q: 生成的PDF文件太大怎么办？
A: 可以在设置中选择"中等"或"低质量"压缩选项。

### Q: 导入大量图片时内存占用很高怎么办？
A: 软件已采用懒加载机制，导入时仅存储压缩字节，预览和生成PDF时按需解压并即时释放。正常情况下内存占用应保持在较低水平。

### Q: 生成PDF时提示某些图片处理失败怎么办？
A: 个别损坏或格式不兼容的图片会被自动跳过，其余图片仍会正常生成PDF。弹窗会列出具体失败的文件名，可单独检查这些文件。

### Q: 如何切换主题？
A: 点击"设置"按钮，在主题设置中选择"浅色"或"深色"。

### Q: 大批量图片生成PDF很慢怎么办？
A: 超过30张图片时会自动启用多进程并行生成，充分利用多核CPU加速。图片越多，加速效果越明显。
